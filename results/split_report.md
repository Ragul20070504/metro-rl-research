**Consequence for the hypotheses.** Residual upward drift inflates forecast error for *every* model equally, so it does not differentially advantage the point-forecast or the uncertainty-aware arm — the H1 comparison stays internally valid. Because the split is chronological, any drift makes the test period harder rather than easier, which is the conservative direction.
